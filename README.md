# Personal Portfolio Website

## Overview

This is my personal portfolio website built using modern web technologies. It showcases my projects, technical skills, and experience as a B.Tech Computer Science student. The portfolio is designed with a clean UI, fast performance, and responsive layout.

## Tech Stack

* React (Vite)
* Tailwind CSS
* JavaScript (ES6+)
* HTML5

## Features

* Fully responsive design
* Modern UI with Tailwind CSS
* Fast performance using Vite
* Projects showcase section
* Skills and tech stack section
* Contact section

## Installation & Setup

1. Clone the repository:

```
git clone https://github.com/satyamsolanki100/portfolio

```

2. Navigate to project folder:

```
cd your-repo-name
```

3. Install dependencies:

```
npm install
```

4. Run the project:

```
npm run dev
```

## Build for Production

```
npm run build
```
